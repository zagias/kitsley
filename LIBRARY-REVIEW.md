# Stored library and urgent-help revision — 25 September 2026

The library previously exposed topic-wide paragraphs and generic five-step outlines. This revision ships editorial content in the application; reading it does not generate AI requests.

## What changed

- All 71 non-safety library entries use a shared illustrated, one-step-at-a-time reader: 29 existing procedures/system guides expanded with tools, technique and specifications, plus 42 three-step observation/planning guides.
- The six safety entries and urgent landing page share focused immediate-action content. The landing page asks which issue is happening; selecting an issue shows three immediate actions together. Gas has its own direct option. Emergency guidance remains visible before selection.
- Original SVG diagrams illustrate measuring, preparation, assembly checks, finishing, diagnosis and immediate safety actions. Diagrams are explanatory, not scale construction drawings.
- Cabinet painting branches by wood, veneer, laminate, MDF or unknown surface. Abrasive grades, compatible primer categories, cabinet enamel examples and product-specific drying guidance are stored content. Paint/primer buying help opens on request.
- Saved project instructions and HTML downloads use the same manual data. Surface choices carry from library to project. Step progress is versioned and invalidated when the surface changes; backup/restore includes these choices.
- Toolbox ownership and existing retailer/referral links remain available within the tools disclosure.

## Evidence and scope

Paint/abrasive facts use Benjamin Moore, Sherwin-Williams, Zinsser and USG references linked in the guide. Specific product timing is labeled as an example, not a universal interval. Unknown surfaces have an identification path without sanding to identify them.

The 42 check-and-plan guides do not promise universal repairs. Wiring, plumbing systems, structural/site work and furniture construction still need appropriate product/design specifications. Existing bookcase drawing validation remains separate. Adding a picture does not validate a construction design.
